# NextPlay

Projeto de conclusão de curso (TCC) do SENAI. O NextPlay é um Sistema de Organização de Eventos de Games que gerencia o ciclo completo do evento, desde o planejamento e cadastro de participantes até o controle das inscrições e perfis dos jogadores.

O desenvolvimento deste repositório foi totalmente focado no Back-end, utilizando Java e Spring Boot com a estrutura MVC:

 **Model:** Onde estruturei as entidades do sistema (como Jogador, Equipe e Partida).
 **Service:** Onde ficaram as regras de funcionamento dos torneios.
 **Controller:** Onde criei as rotas da API para receber os dados.
 **Repository:** Para a comunicação e persistência com o banco de dados.

Foi o meu primeiro grande projeto prático integrando uma API em Java.
